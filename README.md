###Customer Retention Intelligence Dashboard
⚡ Built an end-to-end churn prediction system combining machine learning and business intelligence to identify high-risk customers and reduce revenue loss.

💼 Business Problem
Customer churn is a critical challenge in the telecom industry, directly impacting revenue and growth. This project focuses on identifying why customers leave and who is most likely to churn, enabling proactive retention strategies.

🎯 Objective
Analyze customer churn patterns
Identify key churn drivers
Build a predictive model for churn probability
Segment customers based on risk level
Deliver insights through an interactive dashboard
📊 Dashboard Preview (Power BI)
Dashboard

📈 Key Insights
Customers with Month-to-Month contracts have the highest churn
Electronic Check users show significantly higher churn behavior
Fiber Optic users churn more compared to DSL
Customers without Tech Support are more likely to churn
🧠 Solution Approach
🔹 Data Analysis
Processed 7000+ customer records
Performed Exploratory Data Analysis (EDA)
